# Независимая проверка чистого запуска

`node scripts/verify-clean-start.mjs` проверяет, что продукт запускается из обычного исходного дерева без локальной памяти разработки.

## Что исключается из копии

- `.git`, `.codex` и `.vibemachina`;
- `.env`, `.env.local` и другие приватные environment files;
- `node_modules`;
- `.next`, `.swc`, `.local-data`, `.vercel`, coverage и логи;
- TypeScript build info.

`.env.example`, lockfile, migrations, fixtures, исходники и продуктовые scripts входят в копию. Символические ссылки в включённых путях отклоняются, чтобы clean copy не прочитала файл за пределами репозитория.

## Изоляция

Скрипт создаёт каталог `tirlik-clean-start-*` непосредственно в системном temp, резервирует четыре свободных loopback-порта и вычисляет отдельное имя Compose project из canonical path копии. В дочернее окружение не передаются переменные с ключами, токенами, паролями, auth/session credentials и deployment secrets.

Проверка принудительно задаёт local storage, локальный Workflow, пустой OpenRouter key, новый auth secret и собственные порты. Launcher создаёт отдельный PostgreSQL volume и отдельные файловые каталоги.

## Проверяемый путь

1. Чистый `start.mjs` выполняет `npm ci`, миграции, seed и ждёт health.
2. HTTP-клиент регистрирует аккаунт, workspace и проект.
3. Загружает и повторно читает CSV-источник.
4. Создаёт документ, применяет ручную команду с revision/hash guard и читает новую ревизию.
5. Создаёт настоящие DOCX и PDF, скачивает их и проверяет сигнатуры.
6. Запускает AI-действие без ключа и ожидает явный `configuration` state.
7. Повторно читает ручной результат, чтобы отсутствие модели не блокировало продукт.
8. Останавливает приложение, запускает ту же копию снова и открывает проект, источник, документ и export job.
9. Штатно останавливает приложение и удаляет только проверенные контейнеры и volume этой копии.

При успехе временный каталог удаляется. `--keep` сохраняет успешную копию. При ошибке исходники, `.local-data` и `verification.log` сохраняются, но скрипт всё равно пытается штатно остановить приложение и очистить только подтверждённые собственные Docker resources.

## Запуск

```powershell
node scripts/verify-clean-start.mjs
```

Проверка устанавливает зависимости и запускает Next.js compiler, поэтому её выполняют отдельно от обычного приложения и других сборок. Она требует Docker и доступ к npm registry, если нужных пакетов нет в локальном npm cache.
