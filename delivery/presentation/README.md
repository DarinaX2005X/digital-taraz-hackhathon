Девять слайдов для жюри: возможности Tirlik, новые рабочие материалы, связанное обновление, командный контекст и экспорт. Короткие продуктовые тезисы без подробного учебного кейса.

- [PDF](tirlik-presentation.pdf) и [редактируемый PowerPoint](tirlik-presentation.pptx).
- [Обзор всех слайдов](previews/overview.png); отдельные страницы — в `previews/`.
- [SVG-слайды](slides/) — векторные тексты и фигуры со встроенными растровыми фонами.
- [Содержание и композиции](product_scenes.py), [сборка](build.py), [модель слайдов](scene-model.json).
- [Происхождение материалов](PROVENANCE.md), [проверки](verification.json), [структурный отчёт](inspection.json).

Текст и геометрия PowerPoint редактируются. Два специально созданных тёмных предметных фона используются на слайдах 1, 5 и 9. Иллюстрации объясняют продукт; они не являются снимками интерфейса или результатами клиентских работ.

## Изменение и сборка

Нужен Python 3.11+ с библиотеками из `requirements.txt`. Из корня репозитория:

```powershell
python -m venv .local-data/presentation-venv
.local-data/presentation-venv/Scripts/python.exe -m pip install -r delivery/presentation/requirements.txt
.local-data/presentation-venv/Scripts/python.exe delivery/presentation/build.py
.local-data/presentation-venv/Scripts/python.exe delivery/presentation/check.py --project-root .
```

На macOS/Linux используйте `.local-data/presentation-venv/bin/python`. Обе команды принимают `--output путь`. Проверку файлов можно выполнить отдельно без репозитория, опустив `--project-root`. Сборка читает шрифты из `public/fonts/noto-sans/`; другой каталог задаётся через `--font-dir`.

Для согласованных изменений всех форматов правьте `product_scenes.py` и повторяйте сборку. Прямые изменения PPTX автоматически в Python-исходник не переносятся. После редактирования в PowerPoint новый PDF следует экспортировать из этого редактора.

В PDF встроены Noto Sans Regular и Bold. Для редактирования PPTX с исходной типографикой нужен установленный Noto Sans; в PPTX шрифты не встроены. Лицензия шрифта сохранена в `assets/fonts/OFL.txt`. Формат — 16:9, 13⅓ × 7½ дюйма.

Генерированные фоны уже сохранены. Воспроизведение не вызывает AI, сеть, приложение или базу данных и не требует Codex либо навыков автора.

## Проверка

Проверены границы текстов и фигур, наличие символов, соответствие PDF/PPTX исходной модели, заметки докладчика, шрифты PDF, ссылки, ZIP/XML PPTX и существование файлов, на которых основаны утверждения. PDF растеризован через PDFium; все девять полученных страниц просмотрены. Предпросмотр представляет фактический PDF.

Отображение в PowerPoint/LibreOffice не проверялось: эти редакторы недоступны в среде сборки. Проверка презентации не заменяет пользовательскую визуальную приёмку сайта.
