# Tirlik — продуктовый фильм

Русскоязычная продуктовая анимация: 104 секунды, 1920 × 1080, 60 кадров/с,
H.264 / AAC stereo. 15 сцен показывают постановку задачи, рабочие материалы,
документы, таблицы, дизайн, планирование, закупки, финансы, связанные изменения,
экспорт, команду и повторяющиеся задачи. Это авторская иллюстрация возможностей,
а не запись браузера или результат нового платного запуска.

## Готовые файлы

- `public/video/tirlik-product-film-ru.mp4`
- `public/video/tirlik-product-film-poster.jpg`
- `public/video/tirlik-product-film-ru.vtt`

## Редактирование и сборка

`scenes.py` содержит сцены, камеры, таймлайн, интервалы чтения, 14 явных A/B
переходов и текст субтитров. `engine.py` рисует нативные OpenGL-плоскости,
SDF-материалы, типографику, размытие, свечение и переходы. `audio.py` синтезирует
оригинальную музыку и эффекты по событиям таймлайна. `film.py` — точка входа.

Нужны Python 3.10+, OpenGL 3.3, зависимости из `requirements.txt`, FFmpeg и
FFprobe в PATH. На рабочей машине использованы уже установленные Python 3.10
и Intel Iris Xe; облачные сервисы и загрузка моделей не нужны.

```powershell
python delivery/video/film.py check
python delivery/video/film.py frame --time 40.5 --out .local-data/media/video/frame.png
python delivery/video/film.py render --start 35 --end 47 --width 960 --out .local-data/media/video/preview.mp4
python delivery/video/film.py deliver
```

Последняя команда записывает MP4, постер и VTT в `public/video/`. Другой каталог
можно передать через `deliver --out-dir PATH`. Промежуточная картинка и WAV
хранятся в игнорируемом `.local-data/media/video/`. При изменении только звука
можно повторить финальную сборку с `deliver --reuse-picture`.

Эти Python-пакеты нужны только для пересборки фильма. У сайта нет зависимости
от Python, FFmpeg, OpenGL или файлов из другой папки. Шрифт Noto Sans и знак
берутся из проекта. Саундтрек референса не используется.

## Техническая доставка

Финальная сборка проверяет параметры созданного MP4, полное декодирование и
громкость сжатого саундтрека; сохраняет хеши и измерения в `delivery-report.json`.
Авторские кадры проверялись отдельно от приложения. Просмотр на обычной
скорости, прослушивание и визуальная проверка плеера пользователем не заменяются
этими измерениями и не заявлены как выполненные.
