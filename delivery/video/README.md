# Tirlik — продуктовый фильм v2

На сайте и в корневом README опубликован переданный финальный мастер
`Tirlik_film_v2.mp4`. Файл скопирован без перекодирования или повторного рендера:

- `public/video/tirlik-product-film-v2-ru.mp4` — 65 197 320 байт;
- SHA-256: `38992ee4a6feea77e77523d18ce40296192afb3af913f62f24167299e06a9b71`;
- 104 секунды, 1920 × 1080, 60 кадров/с, H.264, AAC stereo 48 kHz.

У фильма нет отдельного постера в репозитории: постер предыдущей версии удалён,
чтобы он не выдавался за кадр v2. Плеер загружает сам MP4 только после действия
пользователя и не запускает звук автоматически.

Переданный каталог сборки и его команды не копируются в проект, а правообладатель
или лицензия для них не назначаются без данных от автора. В репозитории остаются
Python-исходники предыдущего продуктового фильма. Они полезны как архивный
редактируемый материал, но не являются исходником опубликованного v2 и не должны
использоваться для его воспроизведения.

## Архивный исходник предыдущей версии

`scenes.py`, `engine.py`, `audio.py` и `film.py` относятся к предыдущему фильму.
Для их запуска нужны Python 3.10+, OpenGL 3.3, зависимости из
`requirements.txt`, FFmpeg и FFprobe в PATH. Команды ниже проверяют и собирают
только эту архивную версию:

```powershell
python delivery/video/film.py check
python delivery/video/film.py frame --time 40.5 --out .local-data/media/video/frame.png
python delivery/video/film.py render --start 35 --end 47 --width 960 --out .local-data/media/video/preview.mp4
```

`delivery-report.json` также относится к предыдущей версии. Сайт не зависит от
Python, FFmpeg, OpenGL или внешнего каталога фильма во время запуска.

Метаданные v2 и соответствие байтов исходному мастеру проверены через FFprobe и
SHA-256 без декодирования или просмотра кадров. Визуальная проверка фильма,
прослушивание и проверка плеера в браузере остаются за пользователем.
